# VirusScan
Приложение для сканирования файлов и вирусов на наличие угроз: десктопное клиентское приложение.
## Содержимое
- [Возможности](#возможности)
## Возможности
| Раздел | Что реализовано |
|--------|-----------------|
| **Сканирование** | • Сканирование ссылок (URL) через VirusTotal API<br>• Сканирование файлов (EXE, DOC, PDF, изображения)<br>• Сканирование архивов (ZIP, RAR) с распаковкой<br>• Определение запароленных архивов<br>• Обработка больших файлов (>32 МБ) через двухэтапную загрузку |
| **Кэширование** | • Локальный кэш в памяти (Dictionary)<br>• Кэш на диске (cache.json)<br>• Облачная БД (Supabase PostgreSQL)<br>• Автоматическая очистка кэша (TTL, ограничение размера)<br>• Проверка наличия файла в БД перед сканированием |
| **Анализ результатов** | • Отображение статистики (вредоносные, подозрительные, безопасные)<br>• Список антивирусов, обнаруживших угрозу<br>• Паритет антивирусов (Tier 1, Tier 2, Tier 3)<br>• Анализ от ИИ (DeepSeek) с подробным объяснением<br>• Определение типа угрозы (фишинг, троян, вымогатель) |
| **Пользовательский интерфейс** | • Выбор файла через диалоговое окно<br>• Ввод ссылки для сканирования<br>• Прогресс-бар при сканировании<br>• Отображение результатов в ListBox<br>• Фоновый режим (мониторинг загрузок)<br>• Горячие клавиши (Ctrl+Shift+V) |
| **Безопасность** | • Шифрование API-ключа (ProtectedData)<br>• Хранение ключа в зашифрованном файле (%AppData%)<br>• Защита от Zip-бомб (ограничение размера и количества файлов)<br>• Защита от Zip-Slip (проверка путей)<br>• Обработка ошибок и исключений |
| **Работа с БД** | • Подключение к Supabase (PostgreSQL)<br>• Сохранение результатов сканирования<br>• Получение результатов из БД по хешу<br>• Обновление статуса анализа<br>• Очистка старых записей (pg_cron) |
| **Интеграция с ИИ** | • Анализ результатов через DeepSeek API<br>• Формирование промта для ИИ<br>• Отображение ответа ИИ в отдельном окне<br>• Обработка ошибок API |
| **Логирование** | • Логирование действий пользователя в файл<br>• Информация о сканированных файлах/ссылках<br>• Имя компьютера и дата сканирования<br>• Результаты анализа в логе |
| **Архитектура** | • Клиент-серверная архитектура (WPF + Supabase)<br>• Асинхронные операции (async/await)<br>• Повторные попытки (Polly Retry Policy)<br>• Обработка таймаутов<br>• Отказоустойчивость при недоступности БД |
| **Фоновый режим** | • Мониторинг загрузок (DownloadMonitorService)<br>• Автоматическое сканирование скачанных файлов<br>• Работа в трее (скрытое окно)<br>• Восстановление окна по горячим клавишам |

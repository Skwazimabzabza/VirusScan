# VirusScan
Приложение для сканирования файлов и вирусов на наличие угроз: десктопное клиентское приложение.
## Содержимое
- [Возможности](#возможности)
## Возможности
| Раздел | Что реализовано |
|-------------|-------------|
| Сканирование    | • Сканирование ссылок (URL) через VirusTotal API
                    • Сканирование файлов (EXE, DOC, PDF, изображения)
                    • Сканирование архивов (ZIP, RAR) с распаковкой
                    • Определение запароленных архивов |
| Ячейка 4    | Ячейка 5    |
